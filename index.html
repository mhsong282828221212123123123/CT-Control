차량 BLE 비콘 검색 및 연결

📲 안드로이드 전용 앱(APK) 설치 (iBeacon 차단 우회)
Android 12+의 Chrome 브라우저는 OS 보안 정책(neverForLocation) 때문에 테슬라의 iBeacon(0x004C / S...C) 신호를 차단합니다.
아래 버튼을 눌러 전용 안드로이드 앱(APK)을 설치해 실행하면 차단 없이 차량 신호를 즉시 감지합니다.
⬇️ CT-Control.apk 다운로드 및 설치
🚨 스캔 전 필수 확인 (위치/GPS ON & 슬롯 3개 제한)
• 안드로이드 상단바의 위치(GPS)가 반드시 켜져 있어야 테슬라 iBeacon 패킷이 수신됩니다.
• 테슬라 차량은 동시에 최대 3개의 BLE 기기만 연결할 수 있으므로, 연결이 안 될 때는 메인폰의 공식 Tesla 앱을 강제 종료해 주세요.
💡 차량 BLE 감지 기준 (3중 자동 감지):
• 테슬라 고정 iBeacon: 74278bda-b644-4520-8f0c-720eaf059935
• 비콘 이름 / UUID: S...C / Tesla + 6자리 / 0x1122
※ 음악/통화용 오디오(Tesla Model 3 ...)는 선택하지 마세요.
💳

지금 센터콘솔 컵홀더 뒤편에
실물 NFC 카드키를 태그하세요!

⚠️ 중요: 테슬라 차량은 NFC 카드키를 리더기에 먼저 태그하기 전까지는 화면에 아무런 팝업도 띄우지 않습니다.
카드를 태그하면 차량 모니터에 키 추가 확인 창이 나타나며, 화면에서 승인을 누르면 자동으로 등록이 완료됩니다.
